WOODPECKER CI × MCP

在 Codex 與 Cursor 中
管理 Woodpecker CI。

這個外掛包含 Woodpecker CI 操作指引，並透過本機 stdio MCP 伺服器連線至你的 CI。

開始設定 ↓ 查看原始碼 ↗
本機 stdio MCP Bun 1.1+ 讀取與寫入工具
MCP 伺服器環境變數 本機
WOODPECKER_URL https://ci.example.com/api
WOODPECKER_API_TOKEN 在 MCP 主機中設定

Token 會從 MCP 伺服器的程序環境變數讀取；網址僅供範例。

功能

操作你正在使用的 CI 系統。

01

檢視 CI 執行狀況

查看儲存庫、CI 流水線、建置記錄、執行代理與系統狀態。

02

管理 CI 資源

使用支援的讀取與寫入操作管理 Woodpecker CI 資源，包括機密（secrets）。

03

在本機執行

MCP 伺服器會在本機執行，並連線至你設定的 Woodpecker API。

開始使用

連接你的 MCP 主機。

需要 Bun 1.1 以上版本；Woodpecker API 網址路徑須以 /api 結尾。

C

Codex App

從 GitHub 儲存庫安裝外掛。

git clone https://github.com/jurislm/woodpecker-ci-plugin.git
cd woodpecker-ci-plugin
codex plugin marketplace add .
codex plugin add woodpecker-ci@woodpecker-ci-marketplace

在 MCP 伺服器程序環境中設定 WOODPECKER_URL 和 WOODPECKER_API_TOKEN。macOS 上的 Codex 桌面版不會讀取互動式 shell 設定；詳細步驟請見下方完整設定指南。

↗

Cursor

從 GitHub 匯入外掛。

  1. 開啟 Customize → Add Marketplace → Import from GitHub。
  2. 輸入 jurislm/woodpecker-ci-plugin，新增 Woodpecker CI Plugin。
  3. 在外掛設定中填入 Woodpecker 網址和 Token。
前往 GitHub 儲存庫 ↗
直接設定 MCP 伺服器

其他 MCP 主機可使用 bunx 執行已發布的套件，並在 MCP 伺服器環境變數中設定憑證。請勿提交含有憑證的設定檔。

{
  "mcpServers": {
    "woodpecker-ci": {
      "command": "bunx",
      "args": ["-y", "@jurislm/woodpecker-ci-plugin@latest"],
      "env": {
        "WOODPECKER_URL": "https://ci.example.com/api",
        "WOODPECKER_API_TOKEN": "..."
      }
    }
  }
}

安全與限制

在 MCP 伺服器環境設定憑證。

伺服器會以 Bearer Token 向你設定的 Woodpecker API 驗證。Token 不會寫入記錄或 MCP 工具請求中繼資料。結構化 JSON 回應中可識別的憑證欄位會以 [REDACTED] 遮蔽。請勿將憑證提交到儲存庫。

  • 01 不提供公用 HTTPS /mcp 端點
  • 02 不提供 OAuth 授權流程
  • 03 不讀取 DRONE_TOKEN
